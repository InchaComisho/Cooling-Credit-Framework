## リポジトリの役割

このリポジトリの役割は、クーリングクレジットを最初から再定義することではない。

役割は、評価のための**手順フレームワーク**を提供することである。

```text
定義 → 評価フレームワーク → 実証実装 → 金融・制度設計
```

この構造では、次のように役割分担する。

- Definition は、概念の境界を定義する。
- Framework は、適格性とリスクを評価する。
- Implementation は、現実空間での性能を試す。
- Finance / Governance は、継続的な導入方法を設計する。
