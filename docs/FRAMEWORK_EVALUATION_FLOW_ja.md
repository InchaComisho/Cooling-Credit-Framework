# クーリングクレジット・フレームワーク評価フロー

本書は、**Cooling Credit Framework（クーリングクレジット制度設計案）** を実際に適用するための評価フローを整理する文書である。

このリポジトリは、公式定義と実装の間に位置する「判定手順」の層である。

- **定義層:** [Cooling-Credit-Definition](https://github.com/InchaComisho/Cooling-Credit-Definition)
- **フレームワーク層:** 本リポジトリ
- **実装層:** [Cooling-Credit-Implementation-Portfolio](https://github.com/InchaComisho/Cooling-Credit-Implementation-Portfolio)
- **金融・制度層:** [Cooling-Credit-Implementation-and-Finance-Model](https://github.com/InchaComisho/Cooling-Credit-Implementation-and-Finance-Model)

簡潔に言えば、次の関係である。

> **Definition は、クーリングクレジットとは何かを定義する。**  
> **Framework は、その活動が該当するかを判定する。**  
> **Implementation は、それを現実空間で試す。**  
> **Finance は、それをどう資金化・維持するかを設計する。**

---

## 1. 評価フローの目的

クーリングクレジットは、環境によさそうに見える活動に対して無条件に発行されるものではない。

次のいずれかの成果を、測定・報告・検証できる場合にのみ、評価対象とするべきである。

- 直接冷却
- 熱負荷低減
- 水循環冷却の回復
- 潜熱輸送の回復
- 土壌水分と蒸散の回復
- 海洋・大気熱交換の回復
- 自然冷却機能の回復
- 熱ストレスまたは冷房需要の測定可能な低減

この評価フローの目的は、概念の希釈、グリーンウォッシュ、過大クレジット化、カーボンクレジット・サンシェードクレジット・リフレクトクレジット・適応クレジット・レジリエンスクレジットとの混同を防ぐことである。

---

## 2. 評価ゲート構造

評価プロセスは、7つのゲートで構成される。

| ゲート | 問い | 結果 |
|---|---|---|
| Gate 1: 分類確認 | 主な仕組みは冷却または自然冷却機能の回復か | 違う場合は別分類へ |
| Gate 2: 境界確認 | 炭素会計、日射遮蔽、反射率上昇のみの施策と区別できるか | 違う場合は除外または再分類 |
| Gate 3: 基準線確認 | 信頼できる基準線または対照条件があるか | 不十分なら実証データを要求 |
| Gate 4: MRV確認 | 冷却成果を測定・報告・検証できるか | できなければ発行不可 |
| Gate 5: リスク確認 | 湿度、水資源、生態系、リバウンドなどのリスクを管理できるか | 必要に応じて減点または却下 |
| Gate 6: 帰属確認 | 冷却効果を介入に帰属できるか | 不確実なら未検証扱い |
| Gate 7: 持続期間確認 | 効果は一時的か、季節的か、継続的か | 有効期間を決定 |

これらのゲートを通過したプロジェクトだけが、仮スコア化またはクレジット試算へ進むべきである。

---

## 3. Gate 1: 分類確認

最初に確認するべきことは、その活動が本当にクーリングクレジットの分類に入るかである。

評価対象になり得る成果は、次のようなものである。

- 気温の低下
- 地表面温度の低下
- 水温または海面水温の低下
- WBGTまたは熱ストレス圧力の低下
- 人工排熱の低減
- 土壌水分の回復
- 蒸散の回復
- 水文学的緩衝機能の回復
- 熱調整に関係する海洋混合または溶存酸素の回復
- 環境冷却に起因する冷房エネルギー需要の低減

一方で、主な仕組みが次のものに限られる場合は、原則としてクーリングクレジットではない。

- CO₂会計
- 排出相殺
- 太陽光遮蔽
- 表面の白色化
- アルベド上昇
- 一般的な防災
- 測定可能な冷却を伴わない一般的な適応

これらは価値を持つ場合があるが、直接冷却成果が別途検証されない限り、別分類にするべきである。

---

## 4. Gate 2: 境界確認

境界確認は、**冷却**という言葉の意味を守るために行う。

クーリングクレジットは、既存熱負荷を下げる、または自然冷却過程を回復する介入に限定するべきである。

| 仕組み | 原則的な扱い |
|---|---|
| 直接的な温度低下 | クーリングクレジット評価対象 |
| 水循環回復 | クーリングクレジット評価対象 |
| 土壌水分・蒸散回復 | クーリングクレジット評価対象 |
| 海洋・大気熱交換支援 | 厳格な監視下で評価対象 |
| CO₂削減のみ | 原則としてカーボンクレジット |
| 日射遮蔽 | 原則としてサンシェードクレジット |
| アルベド・反射率上昇のみ | 原則としてリフレクトクレジット |
| 防災のみ | 原則としてレジリエンスクレジット |
| 脆弱性低減のみ | 原則として適応クレジット |

非冷却カテゴリの施策が測定可能な冷却も生む場合は、その冷却成果だけを別途評価できる。

---

## 5. Gate 3: 基準線確認

クーリングクレジットの主張には、基準線が必要である。

基準線は次の方法で設定できる。

- 介入前の測定
- 未処置の対照区
- 過去平均
- リモートセンシング比較
- 季節補正モデル
- 類似地点比較
- 実証実験設計のためのシミュレーション補助推定

基準線が弱い場合でも、実証実験そのものを否定する必要はない。だが、正式なクレジット発行には進めず、測定体制を強化するべきである。

---

## 6. Gate 4: MRV確認

MRVとは、**測定・報告・検証**である。

主な指標には次が含まれる。

- 気温
- 地表面温度
- 水温または海面水温
- WBGT
- 湿度
- 土壌水分
- 蒸散
- 熱フラックス
- 保水量
- 植生回復
- 冷房エネルギー需要
- 排熱低減
- 海洋混合指標
- 溶存酸素
- 生態系応答指標

MRVでは、次を定義する必要がある。

1. 測定境界
2. 基準線の設定方法
3. 監視期間
4. 測定機器
5. 報告間隔
6. 不確実性の範囲
7. 第三者検証の方法
8. リスクと減点条件
9. クレジットの有効期間

---

## 7. Gate 5: リスク確認

冷却は、どんな犠牲を払ってでも行えばよいものではない。

クレジット発行前に、次のリスクを確認する。

| リスク | 例 | 対応 |
|---|---|---|
| 湿度リスク | 高湿度地域でミストがWBGTを悪化させる可能性 | 気温だけでなくWBGTで評価 |
| 水資源リスク | 冷却用水が飲料水や生態系流量と競合する | 雨水、再生水、雑排水、循環水を優先 |
| 生態系リスク | 大規模緑化や海洋介入が生態系を変える | 地域適合性と長期監視を要求 |
| リバウンドリスク | 効率向上により総使用量が増える | 正味の熱負荷効果を監視 |
| 過大クレジットリスク | 短期的な冷却効果を過大評価する | 持続期間と不確実性で減点 |
| リーケージリスク | 熱や水ストレスが別地点に移動する | システム境界全体で評価 |

---

## 8. Gate 6: 帰属確認

冷却成果は、その介入によって生じたものだと説明できなければならない。

帰属確認には、次が使える。

- 前後比較
- 対照地点比較
- センサーネットワーク
- 衛星観測
- 反事実モデル
- 気象補正
- 水文学的監視
- エネルギー使用量監視
- 独立検証

帰属が不確実な場合、そのプロジェクトは実証実験または仮評価に留めるべきである。

---

## 9. Gate 7: 持続期間確認

冷却効果には、持続期間の違いがある。

| 持続期間 | 例 | クレジット上の扱い |
|---|---|---|
| 瞬間的・一時的 | 稼働中のミスト冷却 | 短期有効 |
| 日次反復 | 建物排熱低減 | 稼働実績連動 |
| 季節的 | 植生・土壌水分回復 | 季節検証 |
| 複数年 | 森林、湿地、流域回復 | 長期監視が必要 |
| インフラ型 | 水循環都市システム | 維持管理に連動 |
| 海洋・地域システム | 海洋循環支援 | 厳格な長期監視 |

クーリングクレジットの有効期間は、測定された冷却効果の持続期間と一致させるべきである。

---

## 10. 仮スコア構造

ゲートを通過した後、プロジェクトは仮スコア化できる。

簡略構造は次の通りである。

```text
Cooling Credit Score =
  熱低減
+ 水循環回復
+ 蒸散回復
+ 熱ストレス低減
+ 冷房需要削減
+ 生態的冷却機能回復
- 水ストレス減点
- 湿度リスク減点
- 生態系リスク減点
- 帰属不確実性減点
- 持続期間不確実性減点
```

このスコアは、実証比較、優先順位付け、制度設計に用いる仮評価である。ガバナンス、法的位置づけ、検証方法が別途確立されるまでは、正式な金融商品として扱うべきではない。

---

## 11. 判定結果

評価フローの結果は、次の5分類にできる。

| 結果 | 意味 |
|---|---|
| 適格 | 定義とMRV条件を満たす |
| 仮適格 | 有望だが、測定強化または長期監視が必要 |
| 再分類 | 価値はあるが、別のクレジット分類に属する |
| 除外 | 測定可能な冷却または自然冷却機能回復がない |
| 監視のみ | クレジット化には不確実だが、研究・実証データとして有用 |

## 13. 要約

クーリングクレジットは、検証済みの冷却貢献として扱う前に、構造化された評価プロセスを通過するべきである。

重要な問いは、次ではない。

```text
これは環境によさそうに見えるか。
```

重要な問いは、次である。

```text
信頼できる基準線、MRV、リスク管理の下で、
熱負荷を測定可能に下げたか、または自然冷却機能を回復したか。
```

これが、Cooling Credit Framework の中心的役割である。
