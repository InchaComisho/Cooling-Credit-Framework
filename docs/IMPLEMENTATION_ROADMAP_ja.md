# クーリングクレジット実装ロードマップ

「クーリングクレジットの目的は、最初から金融商品を作ることではない。エルニーニョのような気候リスクが高まる中で、熱負荷を下げる責任を測定可能な形で制度化することである。」

## Phase 0: 構想公開とオープンフレームワーク

- NOTE
- GitHub
- 多言語README
- 関連リポジトリリンク

## Phase 1: 局所測定パイロット

- 校庭
- 農地
- 小規模公園
- 建物外装
- エアコン室外機の排熱低減
- 雨水ミスト試験

目的は、測定方法、基準線設計、単純な前後比較を確立することである。

## Phase 2: エルニーニョ緊急被害低減パイロット

- 緊急都市冷却ゾーン
- 干ばつバッファとしての土壌水分回復
- 雨水貯留と浸透
- 農業暑熱ストレス低減
- 処理水再利用
- 湿地・流域バッファ
- 暑熱リスク監視

この段階では、エルニーニョまたはスーパーエルニーニョのリスク期に、被害低減のための加速的導入を検証する。

## Phase 3: 自治体実証

- 水循環街区
- 都市暑熱センサー
- グリーンコリドー
- 処理水再利用
- 冷却舗装
- 樹冠回復

自治体実証では、熱センサー、水源記録、WBGT測定、街区レベルの冷房需要データを接続する。

## Phase 4: 農地・土壌冷却クレジット

- 有機物回復
- 堆肥と腐葉土
- 土壌水分モニタリング
- 混植
- 蒸発散回復

この段階では、農地と土壌を食料生産や炭素貯留だけでなく、冷却インフラとして評価する。

## Phase 5: 建築・車両の排熱低減

- エアコン排熱冷却
- データセンター排熱削減
- UHVとモビリティ冷却
- 排熱会計

建築物と移動体システムからの人工排熱と冷房エネルギー需要を低減する段階である。

## Phase 6: 地域水循環冷却

- 流域再生
- 森林蒸散回復
- 雨水浸透
- 湿地再生

地域実装では、長期的な保水、蒸発散、地表温度、生態系セーフガードを測定する。

## Phase 7: 海洋・地球冷却統合

- OTU
- 海面冷却支援
- 溶存酸素回復
- セーフガード付きプランクトン支援
- 大規模モニタリング

海洋関連のクレジット化は、保守的で、監視され、生態系セーフガードを条件とする必要がある。

## Phase 8: 制度採用

- 自治体クレジット登録簿
- 国家気候適応政策
- 企業ESG統合
- 国際クーリングクレジット枠組み

制度採用では、クーリングクレジットは測定可能な冷却貢献を証明するものであり、排出許可になってはならないという中核原則を維持する。

## 境界注記：太陽光遮蔽はクーリングクレジットの対象外

クーリングクレジットは、直接的な熱負荷低減と自然冷却機能の回復を測定するために設計されている。太陽光遮蔽、日射制御、成層圏エアロゾル散布は、本ロードマップの主対象外である。これらは将来入ってくる熱を減らすものであり、すでに海洋・土壌・都市・生態系に蓄積された熱を直接下げるものではない。将来的に太陽光遮蔽関連措置を統合する場合には、クーリングクレジット本体の評価とは別の分類とセーフガードが必要となる。
