# エルニーニョ対応統合文書

## 目的

本書は、エルニーニョ／スーパーエルニーニョのリスク下で、クーリングクレジットを被害低減とレジリエンスの制度として緊急導入すべき理由を整理する。「エルニーニョは、長期的な炭素会計を待ってくれない。被害を減らすには、熱負荷低減、水循環バッファ、土壌保水回復、都市冷却、生態系冷却力の回復を、直ちに進める必要がある。」

## エルニーニョと暑熱リスク増幅

エルニーニョは、地域的な猛暑、海洋熱ストレス、干ばつ、降雨パターンの乱れ、生態系不安定化を増幅しうる。クーリングクレジットは、排出量だけでなく、熱曝露を直接下げる行為に価値を与える。

## 干ばつと農業被害

土壌水分、有機物、植生被覆、雨水貯留、処理水再利用、流域保水を回復することで、干ばつリスクを緩和できる。これらは冷却とレジリエンスへの貢献として測定されるべきである。

## 洪水・極端降雨バッファ

エルニーニョは地域によって降雨パターンを変え、洪水リスクを高める場合がある。雨水貯留、浸透、湿地、グリーンコリドー、透水面、流域バッファをクーリングクレジット実証に含める。

## 都市暑熱ストレス

緊急冷却回廊、日陰、樹冠、冷却舗装、保水面、エアコン排熱低減は、高リスク期の熱曝露を下げる。評価には気温だけでなくWBGTを含める必要がある。

## 食料システムリスク

農業冷却実証では、土壌水分、作物周辺温度、蒸発散、灌漑レジリエンスを守る。農地は食料生産だけでなく暑熱リスク低減インフラとして扱われるべきである。

## 海洋昇温と生態系撹乱

海洋監視、溶存酸素回復研究、生態系影響セーフガード、OTU関連研究は、強い監視と生態系セーフガードがある場合に限りクーリングクレジットと接続できる。

## なぜ炭素クレジットだけでは直近の被害を減らせないか

カーボンクレジットは長期的な排出会計を扱う。校庭を冷やす、土壌水分を守る、エアコン排熱を下げる、流域バッファを回復する、短期的な熱曝露を下げるといった被害低減を直接実行する制度ではない。クーリングクレジットはこの実装ギャップを埋める。

## 緊急導入カテゴリ

- 都市冷却回廊
- 雨水貯留
- 処理水再利用
- 土壌水分回復
- 有機物回復
- 植生蒸散回復
- 湿地・流域バッファ
- エアコン・建物排熱低減
- 農業冷却実証
- 海洋監視とOTU関連研究

## El Niñoリポジトリとの関係

関連リポジトリ [El Niño, Super El Niño, Global Warming and Ecosystem Disruption](https://github.com/InchaComisho/El-Ni-o-Super-El-Ni-o-Global-Warming-and-Ecosystem-Disruption) は、リスク構造を整理する。本書は、その緊急性をクーリングクレジットの測定可能な対応カテゴリへ接続する。

## まとめ

クーリングクレジットは、エルニーニョリスク下の実践的な緊急対応・レジリエンス制度として扱うべきである。排出相殺でも排出許可でもない。実際の熱負荷低減、水循環回復、土壌冷却、植生蒸散、排熱削減、生態系冷却力回復を測定する制度である。
