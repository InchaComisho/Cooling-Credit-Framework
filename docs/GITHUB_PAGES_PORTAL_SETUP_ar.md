## نظرة عامة

يحتوي هذا المستودع الآن على بوابة HTML متعددة اللغات:

- [`index.html`](../index.html)

تكتشف الصفحة لغة المتصفح وتنتقل تلقائيًا بين:

- اليابانية
- الإنجليزية
- العربية

كما يمكن تغيير اللغة يدويًا من أزرار اللغة في أعلى الصفحة.

## الهدف

صُممت بوابة HTML لتكون مدخلًا عامًا إلى مستودع `Cooling-Credit-Framework`، وتربط إلى:

- وثائق إطار أرصدة التبريد
- من أرصدة الكربون إلى أرصدة التبريد
- إرشادات MRV
- خارطة التنفيذ
- مقدّر درجة أرصدة التبريد
- محفظة تنفيذ أرصدة التبريد
- نموذج مخلفات الطعام إلى الدبال
- نموذج تحويل الغابات أحادية النبات إلى أصول تبريد
- مفهوم مروحة التبريد بالرذاذ فوق الصوتي المركزي

## طريقة النشر عبر GitHub Pages

على GitHub:

1. افتح المستودع.
2. افتح `Settings`.
3. افتح `Pages` من القائمة الجانبية.
4. ضمن `Build and deployment` اجعل `Source` على `Deploy from a branch`.
5. اجعل `Branch` على `main`.
6. اختر المجلد `/root`.
7. اضغط `Save`.

بعد عدة ثوانٍ أو دقائق، سيعرض GitHub رابط Pages.

صيغة الرابط المتوقعة:

```text
https://inchacomisho.github.io/Cooling-Credit-Framework/
```
