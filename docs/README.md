## Repository Role

The role of this repository is not to redefine Cooling Credits from scratch.

The role is to provide the **procedural framework** for evaluation:

```text
Definition → Evaluation Framework → Pilot Implementation → Finance / Governance
```

In this structure:

- Definition defines the conceptual boundary.
- Framework evaluates eligibility and risks.
- Implementation tests real-world performance.
- Finance and governance design durable adoption.
