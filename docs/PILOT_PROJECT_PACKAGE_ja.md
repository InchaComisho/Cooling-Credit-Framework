# クーリングクレジット実証実験パッケージ

---

## 概要

この文書は、クーリングクレジットを実際に導入・検証するための実証実験パッケージである。

目的は、いきなり国家規模の制度実装を目指すことではない。

まず、学校、公園、駅前、商店街、公共施設、農地、森林、水辺、沿岸地域など、測定可能な小規模実証から始める。

そこで、気温、湿度、WBGT、地表温度、冷房需要、土壌水分、植生、雨水利用、有機物循環などを測定し、クーリングスコアと仮クーリングクレジットへつなげる。

---

## 基本方針

クーリングクレジット実証実験は、以下の順序で行う。

```text
小さく始める
↓
測定する
↓
冷却効果を見える化する
↓
維持管理コストを確認する
↓
クーリングスコアへ変換する
↓
事業モデルへ接続する
↓
拡大可能性を評価する
```

重要なのは、最初から完璧な制度を作ることではない。

現場で測れる冷却効果を積み重ね、企業・自治体・研究者・地域住民が参加しやすい実証モデルを作ることである。

## 実証期間の標準モデル

### 30日実証

短期的な暑熱対策、設置効果、計測体制の確認を行う。

対象例：

```text
学校の校庭
駅前広場
バス停
商店街
公共施設の入口
イベント会場
小規模公園
```

測定項目：

```text
気温
湿度
WBGT
地表温度
利用者の体感アンケート
冷却装置の稼働時間
水使用量
電力使用量
```

---

### 90日実証

夏季全体、梅雨明けから猛暑期、または乾燥期を含めた実証を行う。

対象例：

```text
公共施設
駅前再開発エリア
都市公園
学校・病院・福祉施設
農地の一角
商店街全体
```

追加測定項目：

```text
冷房電力需要
土壌水分
植生状態
雨水・再生水利用量
維持管理費
利用者数
熱中症リスク指標
```

---

### 1年実証

季節変化、維持管理、自然現象への影響を含めて評価する。

対象例：

```text
自治体公共施設群
水源林・里山
農地・果樹園
沿岸漁場
観光地
都市緑地ネットワーク
```

追加測定項目：

```text
年間冷房需要
年間水利用量
土壌有機物量
植生指数
生物多様性の簡易指標
降雨後の保水状況
維持管理体制
事業収支
```

## 実証タイプ

### 1. 都市冷却実証

目的：ヒートアイランド、歩行者暑熱、冷房需要を下げる。

導入例：

```text
ミスト冷却
日陰形成
保水舗装
雨水利用
壁面緑化
屋上緑化
センター超音波ミスト冷却ファン
```

主な評価項目：

```text
気温低下
WBGT低下
地表温度低下
冷房需要低下
利用者数
維持費
水源の持続性
```

---

### 2. 土壌再生実証

目的：土壌の保水力、微生物活動、炭素固定力を回復する。

導入例：

```text
腐葉土投入
有機物循環
化学肥料・農薬依存の低減
マルチング
雨水浸透
微生物回復
```

主な評価項目：

```text
土壌水分
土壌温度
有機物量
作物状態
表面温度
浸透性
保水時間
```

---

### 3. 森林・水源林実証

目的：森林の蒸散、水源涵養、日陰、土壌保水を回復する。

導入例：

```text
単一植生の改善
在来樹種・果樹混植
下草管理
腐葉土層回復
雨水浸透路
小規模水路
```

主な評価項目：

```text
林床温度
土壌水分
植生多様性
樹冠被覆
降雨後の流出量
蒸散ポテンシャル
```

---

### 4. 沿岸・漁場回復実証

目的：海洋循環、酸素供給、漁場回復、海洋熱負荷低減を評価する。

導入例：

```text
低流量エアレーション
ナノバブル送気
海水循環支援
藻場再生
水質モニタリング
非赤潮系プランクトン支援の検討
```

主な評価項目：

```text
水温
溶存酸素
濁度
栄養塩
生物量
漁獲関連指標
海面熱環境
```

## クーリングスコアへの接続

各実証は、測定値をクーリングスコアへ変換する。

例：

```text
気温低下
WBGT低下
地表温度低下
冷房需要削減
土壌水分回復
植生回復
有機物循環量
水循環回復量
維持管理継続性
```

これらを総合し、仮クーリングクレジット単位へ接続する。

初期段階では、正式な金融商品ではなく、実証評価用の仮クレジットとして扱う。

---

## 実証の成功条件

実証実験の成功は、単に温度が下がったかだけで判断しない。

以下を総合評価する。

```text
測定可能であること
再現可能であること
維持管理できること
水源が持続可能であること
周辺環境へ悪影響を与えないこと
費用対効果があること
地域住民が受け入れられること
事業化・制度化へ接続できること
```

---

## 注意事項

クーリングクレジット実証は、誇大な主張を避ける必要がある。

避けるべき表現：

```text
必ず世界平均気温を下げる
雲を増やせば必ず冷える
冷却したから排出してよい
測定なしでクレジット化できる
```

使うべき表現：

```text
局所的・地域的な熱負荷低減を測定する
自然冷却機能の回復可能性を評価する
水循環・土壌・森林・海洋循環への影響を検証する
排出削減と並行して実施する
```
