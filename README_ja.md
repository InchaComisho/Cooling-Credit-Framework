## 自然冷却機能の再起動としてのクーリングクレジット

- [自然冷却機能の再起動としてのクーリングクレジット](docs/NATURAL_COOLING_FUNCTION_RESTART_ja.md)

温暖化対策の本質は、地球の弱体化した自然現象を元に戻し、地球が本来持っていた冷却機能を回復・再起動することにある。

クーリングクレジットは、その回復行為に経済価値を与え、人間社会の欲・利益・投資・事業を、自然再生へ向け直すための制度である。
