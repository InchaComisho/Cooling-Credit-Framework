# 実装メモ

[English Version](README_NOTE.md)

この試算モデルは、概念としてのクーリングクレジット・スコアを、透明で予備的なスコアリングのアルゴリズムに変換します。

意図的に保守的に作られています。

- 冷却へのプラスの貢献と、ペナルティを分けています。
- スコアの出力を、公式なクレジットの発行として扱いません。
- MRVの品質と警告フラグを含みます。
- 同じ構造で、複数のプロジェクトの種類を比較できます。

このモデルは、地域ごとの較正、公式なMRVのプロトコル、センサーデータのパイプライン、ライフサイクル評価、第三者による検証の規則で拡張できます。

今後の拡張の推奨：

1. 地域ごとの水ストレスの表を追加する。
2. WBGT固有の湿度補正を追加する。
3. IoTセンサーの取り込みテンプレートを追加する。
4. プロジェクトの種類ごとの係数を追加する。
5. 可視化のチャートを追加する。
6. 自治体や企業向けの、ウェブフォームまたはノートブックのインターフェースを追加する。
7. 複数のプロジェクト・ポートフォリオにわたる、シナリオの比較を追加する。

このファイルは、現在の試算モデルが、最終的な制度上の標準ではなく、最初の実装レイヤーであることを明確にするために存在します。
