# 免責事項

[English Version](README_DISCLAIMER.md)

クーリングクレジット・スコア試算モデルは、予備的なシミュレーションの道具です。

次のことは行いません。

- 公式なクレジットを発行すること、
- 冷却プロジェクトを認証すること、
- MRVの手続きに代わること、
- 第三者による検証に代わること、
- 気候への成果を保証すること、
- 金銭的な価値を付与すること、
- 法的な適格性を確立すること。

次の用途を想定しています。

- 研究、
- 事前の実現可能性の評価、
- プロジェクトの比較、
- 自治体のパイロット設計、
- 企業の冷却への貢献の計画、
- MRVフレームワークの開発。

将来、公式なクーリングクレジットの制度を設けるには、制度としてのガバナンス、生態系の保全措置、地域ごとの較正、監視のプロトコル、独立した検証が必要になります。
