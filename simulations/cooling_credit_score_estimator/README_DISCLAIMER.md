# Disclaimer

The Cooling Credit Score Estimator is a preliminary simulation tool.

It does not:

- issue official credits,
- certify cooling projects,
- replace MRV procedures,
- replace third-party verification,
- guarantee climate outcomes,
- assign monetary value,
- establish legal eligibility.

It is intended for:

- research,
- pre-feasibility evaluation,
- project comparison,
- municipal pilot design,
- corporate cooling-contribution planning,
- MRV framework development.

Any future official Cooling Credit system would require institutional governance, ecological safeguards, regional calibration, monitoring protocols, and independent verification.
