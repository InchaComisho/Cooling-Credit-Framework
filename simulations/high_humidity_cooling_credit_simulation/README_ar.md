# محاكاة أرصدة التبريد في المناطق عالية الرطوبة

نموذج تمهيدي يقارن بين ثلاثة نماذج تبريد في المناخات الرطبة — موسم الأمطار الياباني، منتصف الصيف، المناطق الجافة الحارة، والمدن الاستوائية عالية الرطوبة.

---

## الغرض

هذه المحاكاة ليست بديلاً عن القياس الميداني، بل نموذج تمهيدي للمقارنة بين استراتيجيات التبريد قبل تنفيذ التجارب.

في المناطق عالية الرطوبة، لا ينبغي تقييم مساهمة التبريد من خلال خفض درجة حرارة الهواء فقط، بل يجب أيضاً تقييم خفض WBGT، وإزالة الرطوبة، ورطوبة التربة، واستعادة دورة الماء، وإمكانات التبريد الموسمية.

يمكن اعتبار موسم الأمطار فترة لإعداد موارد التبريد، من خلال تخزين مياه الأمطار، وإنتاج الدبال، وزيادة رطوبة التربة.

أرصدة التبريد هي محاسبة حرارية وليست محاسبة كربونية — ويمكن تعديل مؤشرات التقييم وفقاً للظروف المناخية الإقليمية.

## النماذج الثلاثة المقارنة

| النموذج | الآلية الرئيسية | أفضل الظروف |
|---|---|---|
| **تبريد الرذاذ التبخيري** | الحرارة الكامنة لتبخر الماء | رطوبة منخفضة (RH < 50%) |
| **إزالة الرطوبة + التبريد بالهواء** | خفض WBGT عبر إزالة الرطوبة | رطوبة عالية (RH ≥ 70%)، موسم الأمطار |
| **مياه الأمطار + الدبال + رطوبة التربة** | تراكم إمكانات التبخر والنتح في التربة | مواسم الأمطار الغزيرة؛ تُعدّ موسم الأمطار فترة تخزين لموارد التبريد الصيفية |

## منطق الحساب (نموذج تصميمي مبسط)

### النموذج 1 — تبريد الرذاذ التبخيري

```python
dryness_factor = max(0, (100 - relative_humidity) / 100)
mist_temp_reduction = 5.0 * dryness_factor * (0.6 + 0.4 * wind_factor)
mist_temp_reduction = min(max(mist_temp_reduction, 0), 5.5)
```

تنخفض الفاعلية بشكل حاد عند ارتفاع الرطوبة. قد تزيد مؤشر WBGT سوءاً عند RH ≥ 70%.

### النموذج 2 — إزالة الرطوبة + التبريد بالهواء

تقريب WBGT المبسط:

```python
wbgt = 0.7 * wet_bulb_temp + 0.2 * globe_temp + 0.1 * air_temp
dehumidified_rh = max(relative_humidity - dehumidification_percent, 35)
```

يُقيَّم خفض WBGT عند خفض الرطوبة النسبية بمقدار 10% و15% و20% و25%.

### النموذج 3 — مياه الأمطار + الدبال + رطوبة التربة

```python
rainwater_storage_score = min(rainfall_mm_week / 80, 1.0)
humus_effect = 0.25
soil_moisture_gain = rainwater_storage_score * 0.25 + humus_effect
evapotranspiration_potential = min(soil_moisture_base + soil_moisture_gain, 1.0)
soil_cooling_potential = evapotranspiration_potential * solar_index * 4.0
```

يُخزَّن إمكانات التبخر والنتح خلال موسم الأمطار لتفعيل التبريد في الأيام المشمسة.

### درجة التبريد المركبة

```python
cooling_score = (
    temp_reduction_c * 1.0
    + wbgt_reduction_c * 1.4
    + soil_cooling_potential * 0.8
    + water_cycle_score * 1.2
)
```

خفض WBGT يحمل وزناً مضاعفاً (1.4×) لإعطاء الأولوية للإجهاد الحراري البشري في المناخات الرطبة.

## النتائج الرئيسية

- **موسم الأمطار (اليابان):** إزالة الرطوبة + التهوية هي الاستراتيجية الأساسية. تبريد الرذاذ غير فعال عند RH 85%. يحقق نموذج مياه الأمطار والدبال أعلى درجة من حيث الإمكانات طويلة الأمد.
- **منتصف الصيف (اليابان):** يصبح تبريد الرذاذ فعالاً عند انخفاض الرطوبة إلى 62%. تساهم الأنماط الثلاثة.
- **المنطقة الجافة الحارة:** تبريد الرذاذ التبخيري يحقق أقصى فعالية. نموذج التربة مقيد بشُح الأمطار.
- **المدينة الاستوائية الرطبة:** إزالة الرطوبة ونموذج مياه الأمطار والدبال يتفوقان على تبريد الرذاذ.

## القيود المهمة

- هذا **نموذج تصميمي مبسط** للمقارنة التمهيدية، وليس محاكاة فيزيائية.
- يستخدم WBGT تقريباً مبسطاً، وليس حساباً نفسجرومترياً كاملاً.
- درجات التبريد بـ**وحدات افتراضية** للمقارنة النسبية فقط.
- التحقق الميداني ضروري قبل اتخاذ قرارات التنفيذ.
