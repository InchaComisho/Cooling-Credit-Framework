# クーリングクレジット実行シミュレーション

## 目的

このディレクトリには、クーリングクレジット制度設計案のための実行可能な概念シナリオモデルを収録する。本モデルは、クーリングクレジットの導入度が、30年間で熱負荷低減、水循環回復、排熱削減、生態系冷却力にどのような相対的影響を与えうるかを比較する。

これは予測モデルではない。複数シナリオの相対的な挙動を確認するための透明な比較ツールである。

## 何をシミュレーションするか

本シミュレーションは、0年目から30年目までの年次ステップで、熱負荷、都市暑熱、地表温度、水循環、土壌水分、植生蒸散、排熱、冷房需要、生態系冷却力、総合的なクーリングクレジットスコアを簡略化された指標として扱う。

「クーリングクレジットは、排出の免罪符ではなく、熱負荷低減、水循環回復、自然冷却機能回復への測定可能な貢献として評価される。」

## シナリオ

スクリプトは次の5シナリオを比較する。

- ベースライン / クーリングクレジットなし
- 低導入
- 中導入
- 高導入
- 統合的地球冷却シナリオ
- エルニーニョ緊急対応シナリオ

## 変数

主な介入変数は、都市冷却導入、水循環回復、土壌水分回復、植生蒸散回復、排熱削減、建築効率、雨水再利用、処理水再利用、有機物回復、海洋冷却支援、緊急暑熱リスク低減、干ばつバッファ、洪水バッファ、食料システム冷却支援である。

また、水ストレス、湿度リスク、生態系リスクのペナルティを含める。これらは、水利用への過度な依存、過剰ミスト、生態系モニタリング不足を伴う介入がある場合に、最終スコアを下げる。

## 実行方法

リポジトリのルートから実行する。

```bash
python simulations/cooling_credit_impact_simulation/cooling_credit_impact_simulation.py
```

実行には `pandas`、`numpy`、`matplotlib` が必要である。

## 結果の読み方

熱関連指標は、値が低いほど相対的な熱負荷や暑熱ストレスが小さいことを示す。エルニーニョ被害リスク指標は、値が低いほど緊急対応シナリオ上の相対的被害リスクが低いことを示す。水循環、土壌水分、植生蒸散、生態系冷却力の指標は、値が高いほど自然冷却機能が回復していることを示す。

クーリングクレジットスコアは複合指標であり、地球平均気温低下量を直接示すものではない。

## 限界

本モデルは、簡略化された関係式と仮定された重みに基づく。大気物理、水文学、海洋力学、生物多様性応答、経済行動を厳密に解くものではない。また、実際の地球平均気温変化を算定するものではない。

## クーリングクレジット制度設計案との関係

本シミュレーションは、制度構想を測定可能な実装へ近づけるための補助モデルである。熱負荷低減、水循環回復、土壌・植生冷却、排熱削減、冷房需要削減、リスクペナルティを組み合わせて評価する考え方を具体化する。

## エルニーニョ緊急対応被害低減との関係

エルニーニョ緊急対応シナリオは、都市暑熱リスク低減、干ばつバッファ、洪水バッファ、農業暑熱ストレス低減、緊急冷却回廊、雨水・処理水再利用、流域回復、必要に応じた海洋監視を含む加速的なクーリングクレジット導入を表す。
